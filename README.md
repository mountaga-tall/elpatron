# EL PATRÓN — Menu 2027

Site statique multi-pages HTML/CSS/JS.

## Structure

- `index.html` — accueil
- `styles.css` — charte graphique + glassmorphisme + responsive + animations
- `app.js` — navigation, panier, WhatsApp, effets WOW
- `icons.js` — icônes SVG inline
- `menu-data.js` — contenu du menu source
- `images/logo.png` — logo fourni
- `pages/*.html` — une rubrique par page + panier + contact
